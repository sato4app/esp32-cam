# 使い方と注意点 - esp32-cam

ESP32-CAMの映像をスマホで見て、写真・動画をmicroSDカードに保存するための手順と注意点をまとめる。
ファームの書き込み方法や通信仕様は [README.md](../README.md) を参照。

## 1. 全体の構成

```
[スマホ（Android Chrome）]
   │  ① 入口ページ（GitHub Pages）── Bluetooth ──▶ ESP32-CAMのアドレスを読み取る・Wi-Fiの接続先を登録する
   │  ② カメラの画面（http://<アドレス>/）── Wi-Fi ──▶ 映像・撮影・録画・ファイル
   ▼
[ESP32-CAM] ── microSDカード（写真・動画を保存）
   ▲
 5V電源（USB・モバイルバッテリーなど）
```

- カメラの画面はESP32-CAM自身が配信する。スマホにアプリを入れる必要はない
- 入口ページは、Wi-Fiの接続先を登録するときと、テザリングでアドレスが分からないときに使う

## 2. 最初に一度だけ行う準備

### 2.1 microSDカード

1. **FAT32** でフォーマットする（exFATは使えない）
   - 32GB以下のカードは、たいてい出荷時からFAT32なのでそのまま使える
   - 64GB以上のカードは出荷時が exFAT。管理者のコマンドプロンプトで `format E: /FS:FAT32 /Q`（E: はカードのドライブ）を実行する。
     受け付けない場合は「Rufus」などのツールでFAT32を選んでフォーマットする
2. 電源を切った状態でESP32-CAMのスロットに差す

### 2.2 secrets.h（ファームを書き込む前）

`firmware/src/secrets.h` に次を書いてから書き込む（作り方は README の「準備と書き込み」）。

| 項目 | 内容 |
|---|---|
| `BLE_PASSKEY` | Bluetoothのペアリングに使う6桁の暗証番号。Wi-Fiの接続先を登録するとき、スマホで一度だけ入力する |
| `AP_PASSWORD` | アクセスポイントモードのパスワード |

Wi-Fiの接続先（テザリングなど）は、書き込んだ後に入口ページから登録する（2.5）。

### 2.3 スマホのテザリング設定（テザリングで使う場合）

Pixelの場合: 設定 → ネットワークとインターネット → アクセスポイントとテザリング → Wi-Fiアクセスポイント

| 項目 | 設定 | 理由 |
|---|---|---|
| 互換性を拡張 | ON | OFFだと5GHz帯になり、2.4GHzにしかつながらないESP32-CAMから見えない |
| セキュリティ | WPA2-Personal | WPA3のみだとつながらないことがある |
| アクセスポイント名・パスワード | 入口ページで登録したものと同じ | 変えたら登録し直す |

### 2.4 入口ページをホーム画面に追加

1. Androidの Chrome で `https://sato4app.github.io/esp32-cam/` を開く
2. Chromeのメニューから「ホーム画面に追加」（または「アプリをインストール」）を選ぶ

スマホのBluetoothと位置情報をONにしておく（Web Bluetoothに必要）。

### 2.5 Wi-Fiの接続先（テザリング）を登録する

ESP32-CAMは、**電源を入れてから5分間だけ**接続先の登録を受け付ける。

1. スマホのテザリングをONにする
2. ESP32-CAMの電源を入れる（ここから5分以内に3〜5を行う）
3. 入口ページの「Wi-Fiの接続先を登録」に、テザリングのWi-Fi名（SSID）とパスワードを入れて「ESP32-CAMに送る」を押す
4. 一覧に出る「ESP32-CAM」を選ぶ
5. 初めてのときはスマホに「ペアリング」の画面が出るので、`BLE_PASSKEY` の6桁を入力する
6. 「○○につながりました」と出れば完了。表示されたアドレスでカメラの画面を開ける

- 登録した接続先はESP32-CAM本体に残る（電源を切っても、ファームを書き込み直しても消えない）
- 最大5件まで登録できる。超えると最も古いものが消える
- 「登録済みの接続先を見る」で一覧を表示し、「削除」で消せる（削除も電源投入後5分以内のみ）
- ペアリングは2回目から不要。パスワードは登録後にBluetoothで読み出すことはできない
- テザリングのWi-Fi名やパスワードを変えたら、同じ手順で登録し直す

## 3. カメラの画面を開く

ESP32-CAMは起動すると、登録したWi-Fiに20秒間つなぎにいく。
つながらなければ、自分がアクセスポイント（Wi-Fi名 `ESP32-CAM`）になる。使う場所に合わせて、次のどれかで開く。

### 3.1 スマホのテザリングで使う（外出先）

1. スマホのテザリングをONにする
2. ESP32-CAMの電源を入れ、20秒ほど待つ
3. 入口ページを開き、「Bluetoothで探して開く」を押す
4. 一覧に出る「ESP32-CAM」を選ぶ → カメラの画面が開く

- 一度開いたアドレスは入口ページに「前回のアドレス」として残る。テザリングを入れ直していなければ、そのボタンでも開ける
- 入口ページに「アクセスポイントモード」と出たら、ESP32-CAMがテザリングにつながっていない。
  テザリングがONか確かめて30秒〜1分待ち、もう一度探す（ESP32-CAMは30秒ごとに登録したWi-Fiを探し直す）

### 3.2 家のWi-Fiで使う

1. スマホとESP32-CAMを同じWi-Fiにつなぐ
2. ブラウザで ESP32-CAM のアドレス（例: `http://192.168.1.23/`）を開く

アドレスは、USBでPCにつないでシリアルモニタを開くと表示される（Enterキーで再表示）。
ルーターは普通、同じ機器に同じアドレスを割り当てるので、一度分かればブックマークしておけばよい。
入口ページの「Bluetoothで探して開く」も使える。

### 3.3 Wi-Fiがない場所で使う（アクセスポイントモード）

1. ESP32-CAMの電源を入れ、20秒ほど待つ
2. スマホのWi-Fi設定で `ESP32-CAM`（パスワードは `secrets.h` の `AP_PASSWORD`）につなぐ
3. 「インターネットに接続されていません」と出ても、そのまま接続を維持する
4. ブラウザで `http://192.168.4.1/` を開く

この間スマホはWi-Fiでインターネットにつながらない（モバイル通信は使える）。

## 4. カメラの画面の操作

### 4.1 画面の構成

| 場所 | 内容 |
|---|---|
| 右上の表示 | 「接続中」（緑）・「録画中」（赤）・「カメラ異常」・「未接続」 |
| 映像 | ライブ映像。左上に録画中の「REC」と経過時間、右上にコマ数（fps） |
| 映像右下のボタン | 「一時停止」で映像を止める（もう一度押すと再開）。「⛶」で全画面 |
| 撮影ボタン | 📷 撮影・● 録画・📱 静止画 |
| ライト | フラッシュLEDの明るさ |
| カメラ設定 | 解像度・画質・向き |
| microSDカード | 空き容量と保存したファイルの一覧 |
| 接続情報 | つないでいるWi-Fi・アドレス・Bluetoothの状態・時刻・稼働時間 |

### 4.2 撮影・録画

| ボタン | 動き | 保存先 |
|---|---|---|
| 📷 撮影 | 今の映像を写真で保存する。画面が一瞬白く光る | microSD |
| ● 録画 | 押すと録画開始（ボタンが■に変わる）、もう一度押すと停止 | microSD |
| 📱 静止画 | 今の映像を1枚、スマホのダウンロードフォルダに保存する | スマホ |

- 録画中は基板裏の赤色LEDが点滅する
- 録画は10分ごとに自動で次のファイルに分かれる（映像の「REC」の横に何本目かが出る）
- 録画中に画面を閉じても、録画は続く。止めるときは画面を開き直して ■ を押す

### 4.3 ライト

スライダーで0〜100%に変える。暗い場所での撮影に使う。
明るくすると基板が熱くなるので、必要なときだけ点ける。

### 4.4 カメラ設定

| 項目 | 内容 |
|---|---|
| 解像度 | 320×240〜1600×1200。上げるほど細かくなるが、コマ数が減りファイルが大きくなる。録画中は変えられない |
| 画質 | 数字が小さいほどきれいでファイルが大きい。迷ったら 12 |
| 向き | 映像が上下逆なら「上下反転」、左右逆なら「左右反転」。両方で180度回転 |

設定はESP32-CAMに保存され、電源を切っても残る。

解像度とコマ数の目安

| 解像度 | 用途 | コマ数の目安 |
|---|---|---|
| VGA 640×480 | 普段の確認・長時間の録画 | 15〜25fps |
| SVGA 800×600 〜 HD 1280×720 | 少し細かく見たいとき | 10fps前後 |
| UXGA 1600×1200 | 写真を細かく撮りたいとき | 数fps |

### 4.5 保存したファイル

「microSDカード」の一覧に、新しい順で表示される（30件ずつ。「もっと見る」で続きを表示）。

| ボタン | 動き |
|---|---|
| 表示（写真） | 写真を全画面で表示する。「ダウンロード」でスマホに保存 |
| 保存（動画） | 動画をスマホにダウンロードする |
| 削除 | ファイルを消す（元に戻せない） |
| 更新 | 一覧を読み込み直す |

ファイルは microSD の `DCIM` フォルダに、撮った日時の名前で保存される。

| 種類 | ファイル名の例 |
|---|---|
| 写真 | `IMG_20261007_123456.jpg` |
| 動画 | `VID_20261007_123456.avi` |

- 時刻は、テザリングや家のWi-Fiではインターネットで、アクセスポイントモードでは画面を開いたスマホの時刻で合わせる。
  時刻が合う前に保存したファイルは `IMG_0001.jpg` のような連番になる
- microSDをPCに差して、`DCIM` フォルダから直接コピーしてもよい（ESP32-CAMの電源を切ってから抜く）

### 4.6 動画の再生

動画は AVI（MJPEG）形式で、**スマホのブラウザでは再生できない**。
ダウンロードしてから **VLC** などの動画アプリで再生する（PCでも同じ）。

## 5. バッテリーで使う

書き込んだプログラムはESP32-CAMに残るので、USBを外して電池で動かせる。

| 電源 | つなぎ方 | 使えるか |
|---|---|---|
| モバイルバッテリー | ESP32-CAM-MBにUSBでつなぐ | ○ いちばん確実 |
| リチウム電池（3.7V）＋5V昇圧モジュール | ESP32-CAMの 5V・GND ピンへ | ○ |
| 単3ニッケル水素電池×4本（約4.8V） | 5V・GND ピンへ | △ 電池が減ると不安定 |
| リチウム電池（3.7V）を直接 | 5V ピンや 3.3V ピンへ | × 電圧が合わない |

- 1A以上出せる電源を使う。動作中は0.2〜0.3A流れ、ライトを点けるとさらに増える
- 使える時間の目安は、5000mAhのモバイルバッテリーで10時間前後（ライトを点けない場合）
- 電流が少ないと自動で切れるモバイルバッテリーがある。止まる場合は「低電流モード」付きの製品を使う

## 6. 注意点

### 6.1 使い方の制限

- **映像を同時に見られるのは1台だけ**。2台目は1台目が画面を閉じるまで表示されない。
  画面を閉じる・別アプリに切り替えると、自動で配信を止めて枠を空ける
- **映像を一度表示するとBluetoothは止まる**（映像を速くするため）。
  入口ページでもう一度探したいときは、ESP32-CAMのRSTボタンを押すか電源を入れ直す。
  テザリングを入れ直してアドレスが変わったときは、自動で通知を再開する
- **Wi-Fiの接続先の登録は、電源を入れてから5分以内だけ**。映像を表示するとBluetoothが止まるので、登録は映像を見る前に行う
- つながっていたWi-Fiが切れて1分たっても戻らないと、ESP32-CAMはアクセスポイントモードに切り替わる（その後も30秒ごとに登録したWi-Fiを探す）
- 動画のダウンロード中は、録画のコマ数が落ちることがある
- 入口ページ（HTTPS）の中では映像を表示できない。入口ページはカメラの画面へ移動するだけ

### 6.2 データの扱い

- **録画中に電源を切らない**。録画中のファイルが再生できなくなることがある（VLCの「壊れたAVIを修復」で見られる場合がある）。
  必ず ■ で停止してから電源を切る
- microSDがいっぱいになると録画は自動で止まり、画面にエラーが出る。空きが20MB未満だと録画を始められない
- 削除したファイルは元に戻せない
- カメラの画面は暗号化なし（HTTP）で配信する。同じWi-Fiにつないだ人は画面を開けるので、人の多いWi-Fiでは使わない

### 6.3 ハードウェアの扱い

- **長時間動かすと基板がかなり熱くなる**。ケースに入れる場合は風通しを確保する。ライトを明るくすると特に熱くなる
- microSDカードの抜き差しは電源を切ってから行う
- カメラのフラットケーブルは抜けやすい。動かした後に「カメラ異常」が出たら差し直す

## 7. 困ったとき

| 症状 | 原因と対処 |
|---|---|
| 右上に「カメラ異常」、映像が出ない | カメラのフラットケーブルが外れかけている。電源を切り、コネクタの黒いロックを開けてケーブルを奥まで差し、ロックを閉じる。映像部分に出る理由（エラー番号）も確認する |
| 入口ページで「ESP32-CAM」が見つからない | ① スマホのBluetooth・位置情報がOFF ② すでに映像を表示したためBluetoothが止まっている → RSTボタンを押す ③ 電源が入っていない |
| 入口ページに「アクセスポイントモード」と出る | テザリングにつながっていない。テザリングがONか、「互換性を拡張」がONか、登録したWi-Fi名・パスワードが合っているかを確かめる。未登録なら「Wi-Fiの接続先を登録」から登録する |
| 登録で「受付時間外です」と出る | 電源を入れてから5分を過ぎた。ESP32-CAMのRSTボタンを押すか電源を入れ直し、5分以内に送る |
| 登録で「ペアリングできませんでした」と出る | 暗証番号の入力を間違えた、または入力が間に合わなかった。もう一度送る。何度も失敗する場合は、スマホのBluetooth設定で「ESP32-CAM」を削除（登録を解除）してからやり直す |
| 右上に「未接続」 | スマホとESP32-CAMが別のネットワークにいる、またはESP32-CAMの電源が切れた。同じWi-Fiか確かめ、入口ページで探し直す |
| 「映像が届きません」と出る | 他の端末（PCなど）で映像を開いている。そちらを閉じる |
| 映像が遅い・カクカクする | 解像度を下げる、画質の数字を上げる、スマホとESP32-CAMを近づける。接続情報の電波が -75 dBm より弱いと遅くなりやすい |
| 「microSDカードが見つかりません」 | カードが差さっていない、またはFAT32でない（exFATなど）。FAT32でフォーマットし直す |
| 起動直後に再起動を繰り返す | 電源不足。短く太いUSBケーブル、1A以上出せる電源を使う |
| ファイル名が `IMG_0001.jpg` のような連番になる | 時刻が合う前に保存した。画面を一度開けばスマホの時刻で合う |
| 動画がスマホで再生できない | AVI形式のため。VLCなどの動画アプリで開く |
